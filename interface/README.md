# interface/

Painel do operador: vídeo da ESP32-CAM, controles, identificação do Balloone e
status (conexão, FPS, ping, bateria).

O edital pede que a interface tenha, preferencialmente:
transmissão da ESP32-CAM · comandos de controle · identificação do Balloone ·
informações adicionais relevantes.

Lembrete: a competição é ao ar livre, às 10h. Alto contraste e botões grandes.
